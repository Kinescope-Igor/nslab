# NSLab — кросс-платформенный benchmark, 2026-05-17

URL: https://speak.kn.pe/lab/noise-bench/

Test signal: 10 sec pink noise + 1 kHz sine @ 48 kHz. Для 16 kHz моделей
resample 48→16 включён в per-frame latency.

Цвета RTF: **<0.3** — большой запас; **<1.0** — real-time на грани; **≥1.0** — не успевает.

## Главные выводы

1. **DFN-3 — real-time везде** (RTF < 0.2 на всех 14 успешных платформах,
   включая iPhone 13 и macOS Ventura). Топ-1 кандидат для production Speak.
   Cold-frame от 4 до 24 ms.

2. **macOS Sequoia / Win 11 — top-tier**:
   - Chrome/Edge macOS Sequoia: DFN-3 RTF 0.049-0.050 — **в 20× запас**
   - Safari macOS Sequoia: 0.050 — на уровне Chromium
   - Все Win10/11 Chrome/Edge/Firefox: 0.082-0.103 (5-10× запас)

3. **macOS Ventura — деградация ~2-5×**:
   - Safari Ventura GTCRN RTF 0.469 vs Sequoia 0.093 (в 5× хуже, p99 47ms)
   - Chrome Ventura DFN-3 0.111 vs Sequoia 0.049
   - Старые версии WebKit/Safari ML-WASM JIT слабее. **Рекомендация**
     минимум macOS Sequoia для Mac-юзеров Speak.

4. **WebGPU не имеет смысла** для NSLab-моделей:
   - Pixel 8: RTF 13.2 vs WASM 0.238 (в 55× медленнее)
   - Chrome macOS Sequoia: 1.217 vs 0.074 (в 16× медленнее)
   - Chrome macOS Ventura: 3.266 vs 0.205 (в 16× медленнее)
   - Shader compile dominate, для tiny моделей это anti-optimization.

5. **iOS Safari + GTCRN OOM** — onnxruntime-web 1.26 default тянет
   JSEP-build (26 MB), iOS Safari не выделяет столько contiguous WASM heap
   на iPhone. Override `ort.env.wasm.wasmPaths` к non-JSEP `.wasm` файлу
   (13 MB) не помогает — нужен правильный entry-point import (отдельная
   инженерная задача).

6. **Firefox macOS hangs** — таймаут даже на 360s. Локально и на Win 11
   Firefox работает (RTF 0.082-0.092 для DFN-3 — отлично). Похоже
   специфика BrowserStack Firefox+macOS+ORT/TFLite WASM JIT.

7. **Edge ≈ Chrome** на обеих OS (оба Chromium): идентичные RTF, идентичный
   webgpu anti-opt. Для бенчмарка хватит одного.

8. **Win10 ≈ Win11** для одного браузера: разница в пределах 5-10%.
   Win10 не блокирует пользователей Speak.

## Безопасный default для Speak команды

- **macOS Sequoia / любой современный браузер** → DFN-3 (топ-качество, real-time).
- **macOS Ventura и старее** → DFN-3 (тоже real-time, но GTCRN заметно деград'нет).
- **Win 10/11 любой Chromium/Firefox** → DFN-3.
- **iOS Safari** → DFN-3 (GTCRN не загружается из-за ORT-bundle).
- **iOS / любая старая Android** → RNNoise как fallback (минимальная нагрузка).
- **WebRTC NS** — нулевой overhead, всегда работает как baseline.

## Известные нерешённые вопросы

- **iOS Safari + GTCRN OOM** — требует ORT non-JSEP bundle (отдельный entry,
  или manual webpack split, или ORT 1.x без JSEP).
- **Firefox macOS Sequoia hangs** на BrowserStack — повторить с детальным
  console capture или тестировать через локальный Mac.
- **Galaxy A52 osVersion 11.0** не поддерживается на BS, нужен другой
  бюджетник (A53, A54, Moto G Power, OnePlus Nord).
- **Mem MB** — `performance.memory` есть только в Chromium, и delta JS-heap
  не отражает WASM-heap. Нужен другой API (например
  `performance.measureUserAgentSpecificMemory`, требует COOP/COEP).
