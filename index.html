Производительность

Модель Backend RTF cold ms p50 p95 p99 Mem MB SR

10 сек pink noise + 1 kHz sine @ 48 kHz (как реальный mic). Для 16 kHz моделей resample 48→16 включён в per-frame latency. DTLN мерится через OfflineAudioContext (wall-time, без per-frame статистики). WebRTC NS не включён — это native APM браузера, изолированно не измерить. Mem MB — delta JS heap (включает WASM); только в Chromium-браузерах, иначе «—». GTCRN прогоняется по всем доступным ORT backends (wasm всегда, webgpu/webnn — runtime-детект).

Громкость +9.5 dB

Микрофон без AGC обычно тихий. Усиление применяется ПОСЛЕ шумодава, чтобы не сбить VAD/маску. 1× = 0 dB, 3× = +9.5 dB, 6× = +15.6 dB.
